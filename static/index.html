Pipeline Sync

Trigger a complete re-training cycle using fresh data distributions. The system automatically recalculates hyperparameters, fits the Random Forest pipeline, writes new artifacts to disk, logs the audit record in SQLite, and hot-reloads inference memory without downtime.

REST API Endpoints & Developer Integration

Clean JSON APIs designed for real-world integration. Ready to consume from any frontend, mobile app, or backend microservice.

Open Interactive Swagger UI →
POST /api/predict

Executes ML inference on applicant payload, determines risk tier and APR, and persists complete record into SQLite.

curl -X POST http://127.0.0.1:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "applicant_name": "Elena Rostova",
    "age": 34,
    "annual_income": 85000,
    "credit_score": 740,
    "loan_amount": 20000,
    "loan_term_months": 36,
    "employment_years": 5.5,
    "debt_to_income_ratio": 18.5,
    "home_ownership": "MORTGAGE",
    "loan_purpose": "home_improvement",
    "has_prior_default": false
  }'
GET /api/predictions

Retrieves stored records with pagination, text search (name, UUID), and filtering by risk tier or decision.

curl "http://127.0.0.1:8000/api/predictions?page=1&size=10&risk_tier=Low+Risk"
GET /api/stats

Returns live aggregate metrics: approval rate, total loan volume, average credit score, and risk distributions.

curl "http://127.0.0.1:8000/api/stats"
PATCH /api/predictions/{id}

Update review status (e.g. manual underwriting override) or notes on a stored decision.

curl -X PATCH http://127.0.0.1:8000/api/predictions/1 \
  -H "Content-Type: application/json" \
  -d '{"review_status": "APPROVED_OVERRIDE", "notes": "Approved with senior loan officer sign-off."}'
